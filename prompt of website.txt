===========================================================
PROJECT OVERVIEW
===========================================================

Build a recruitment platform specifically designed for the restaurant and hospitality industry.

The purpose of this platform is to connect:

1. EMPLOYERS
(Restaurants, Hotels, Cafes, Cloud Kitchens, Bakeries, Catering Services, Canteens)

with

2. APPLICANTS
(Chefs, Cooks, Kitchen Staff, Restaurant Workers, Hospitality Professionals)

The platform will allow EMPLOYERS to post job openings and allow APPLICANTS to search and apply for suitable jobs.

The complete platform will be managed by an ADMIN.

The website should be simple, reliable, professional, easy to maintain, and scalable.

Do not create unnecessary complexity.

Focus on:

• Working functionality
• Clean UI/UX
• Secure data handling
• Easy navigation
• Good performance
• Beginner-friendly maintenance

AUTHENTICATION & PASSWORD SYSTEM
===========================================================

Implement a secure and user-friendly authentication system for:

• ADMIN
• EMPLOYER
• APPLICANT


Registration Requirements:

• Users register using email.
• Email verification should be supported.
• Passwords must never be stored as plain text.


Password Rules:

• Minimum password length: 6 characters.
• Accept any combination of characters if minimum length is satisfied.
• Do not force uppercase, lowercase, numbers, or special characters.
• Keep the system simple for users.


Reject only extremely weak passwords such as:

• 123456
• 12345678
• password
• password123
• admin
• admin123
• qwerty
• abc123
• 111111
• 000000


If a weak password is entered:

Show a message asking the user to choose a stronger password.


LOGIN:

Users login using:

• Registered email
• Password


Provide:

• Error messages for incorrect login
• Logout option
• Secure sessions


FORGOT PASSWORD:

Every login page must have:

"Forgot Password?"


When selected:

• User enters registered email.
• Send secure password reset email.
• Allow user to create a new password.
• User can login again with the new password.
